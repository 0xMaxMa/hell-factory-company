# test-paid

**Paid test job for e2e verification of payment flow.**

This job costs **$5** upfront (BEP-20 / BNB Chain). Used only for automated testing of the payment gate in `/job-run`.

## What it does
Prints a timestamp + "PAID JOB OK" to confirm the job ran after payment was verified.

## Requirements
- $5 initial capital (paid via crypto, BEP-20)
- No other dependencies

## Output
```
[TIMESTAMP] PAID JOB OK
```
